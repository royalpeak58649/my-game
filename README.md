# 1836

This is an original 1836 grand strategy game: a from-scratch simulation of the world in the mid-1830s, where you guide a nation through diplomacy, economy, and war on a map built from open geographic data — no assets or code from any existing commercial game are used.

## Setup

```bash
npm install
npm run dev    # start the dev server
npm test       # run the unit tests
npm run build  # type-check and build for production
```
