# Fixer City (해결사의 도시)

프로젝트문 '도시' 세계관에서 해결사로 살아가는 세미 하드코어 마인크래프트 모드.
NeoForge **1.21.1** 기반.

> 이 브랜치(`fixer-city`)는 `my-game` 저장소와 별개의 프로젝트입니다.

## 설치

1. [NeoForge 1.21.1](https://neoforged.net/) 설치
2. 저장소 **Releases**에서 가장 최근 `fixercity-build-N`의 `fixercity-*.jar`를 받아 `mods` 폴더에 넣기
3. 같이 플레이하는 친구 모두(서버 포함) 같은 jar를 넣어야 합니다

## 현재 구현된 것: 해결사 장비

|---|---|---|
| 해결사 장검 | 공격력 8 / 공속 1.4 | **돌진 베기**: 5칸 돌진하며 경로의 적을 벤다 (5초) |
| 해결사 철퇴 | 공격력 11 / 공속 0.8 | **내려찍기**: 반경 3.5칸 피해+넉백+구속, 낙하 중이면 최대 2배 (8초) |

모든 장비는 제작대 레시피가 있고, 크리에이티브 탭 **해결사 장비**에도 있습니다.

## 시작과 죽음

### 첫 접속: 키트 5개
처음 접속하면 아래 5종 중에서 **무작위로 키트 5개**(중복 가능)가 **키트 보관함**에 들어온다.
`/kit`으로 보관함을 열고 `[꺼내기]`를 클릭하면 그 키트가 바로 장비된다 (갑옷 착용, 책장·장신구 장착).
하나를 쓰고 나머지는 **죽은 뒤 다시 시작할 때** 쓰면 된다. 보관함은 월드에 저장되므로 죽어도 남는다.
죽고 리스폰하면 보관함 목록이 자동으로 뜬다.

| 키트 | 구성 |
|---|---|
| 검객 | 장검, 해결사 정장, 사무소 해결사 책장 |
| 중장 | 철퇴, 방탄 코트, 사무소 해결사 책장 |
| 암살자 | 단검, 연막탄, 해결사 정장, 사무소 해결사 책장 |
| 총잡이 | 리볼버, 탄환 12, 단검, 해결사 정장, 사무소 해결사 책장 |
| 뒷골목 출신 | 쇠파이프, 응급 키트 2, 섬광탄, 쥐 패거리 책장, 행운의 동전 (갑옷 없음) |

모든 키트에 빵 8개. 5개를 다 쓰면 그다음부터는 의뢰로 번 돈으로 장비를 사야 한다.
OP는 `/fixerkit <swordsman|brawler|assassin|gunner|backstreet> [플레이어]`로 키트를 바로 줄 수 있다.

### 죽음
- **인벤토리, 갑옷, 손에 든 것이 전부 사라진다** (바닥에 떨어지지 않음, `keepInventory`와 상관없이).
- 낀 **책장과 장신구도 사라진다**.
- 평판 5% 감소 (최소 5).
- **남는 것: 돈(안), 평판, 키트 보관함, 엔더 상자.** 엔더 상자는 사실상 개인 금고다.
- 크리에이티브·관전 모드는 예외.

## 의뢰와 평판

### 의뢰 게시판
**의뢰 게시판** 블록(판자 6 + 종이 2 + 책)을 놓고 우클릭하면 **의뢰 게시판 화면**이 열린다. `수락`, `보고`, `포기`, `협회 상점` 버튼을 누르면 된다. 의뢰 위에 마우스를 올리면 목표와 보수가 보인다.
(채팅 버전도 남아 있다: 게시판 근처에서 `/request board`)
- 게시판에는 늘 6개의 의뢰가 걸려 있고, 마인크래프트 하루마다 바뀐다. 의뢰 등급은 연 사람의 등급 근처로 나온다.
- 내 등급보다 **한 단계 높은 의뢰까지** 받을 수 있다. 한 번에 의뢰 하나.
- 수락할 때 **게시판 8칸 안에 있던 플레이어와, 접속 중인 같은 사무소원 전원이 함께 팀**이 된다. 보수(안)는 나눠 갖고, 평판은 각자 전부 받는다.
- 목표를 이루면 아무 게시판이나 우클릭해서 보고하면 보수를 받는다.
- 기한을 넘기거나 포기하면 평판이 깎인다.

| 종류 | 내용 | 보수 배율 | 기한 |
|---|---|---|---|
| 토벌 | 특정 몹 N마리 (팀원 누가 잡아도 셈) | x1.0 | 2일 |
| 현상금 | 200~450칸 떨어진 곳에 가면 **현상범**이 나타난다. 처치 | x1.5 | 3일 |
| 납품 | 물건 N개를 게시판에 가져와 `[보고]` | x0.8 | 3일 |
| 현장 조사 (7~9급) | 지정 좌표에 가 본다 | x0.6 | 2일 |

**현상범**은 조직원(쥐 패거리 두목, 타락한 해결사, 협회 이탈자, 엄지 솔다토, 쿠로쿠모 행동대장)이다. 조직 무기를 들고, 그 조직 책장의 내성을 가지며, 등급이 높을수록 체력과 공격력이 크다. 쓰러뜨리면 **그 조직의 책장(35%), 무기(30%), 장신구(25%)**를 떨어뜨릴 수 있다.

### 평판과 등급
| 등급 | 9급 | 8급 | 7급 | 6급 | 5급 | 4급 | 3급 | 2급 | 1급 |
|---|---|---|---|---|---|---|---|---|---|
| 필요 평판 | 0 | 100 | 300 | 700 | 1,500 | 3,000 | 6,000 | 10,000 | 16,000 |

- 1급 위에는 **특색**이 있다 (평판 25,000). 서버 전체에 특별 알림이 뜨고, 이름 앞에 금색 `[특색]`이 붙는다.
- 승급하면 서버 전체에 알림이 뜬다. 채팅과 탭 목록 이름 앞에 `[7급]`처럼 등급이 붙는다.
- **죽으면 평판 5% (최소 5)를 잃는다.** 평판이 떨어지면 강등될 수 있다.

### 사무소
친구들끼리 고정 팀을 만든다. **사무소원은 어디에 있든 접속 중이면 의뢰에 함께 참여**한다 (게시판 근처에 모일 필요 없음). 탭 목록에 `[사무소명]`이 붙는다.

| 명령어 | 설명 |
|---|---|
| `/office create <이름>` | 사무소 결성 (500안, 한글 가능, 16자까지) |
| `/office invite <플레이어>` | 초대 (대표만). 상대는 채팅의 `[가입]` 클릭 |
| `/office join <이름>` | 초대받은 사무소에 가입 |
| `/office` | 사무소 정보와 사무소원 등급 |
| `/office leave` / `/office kick <플레이어>` | 탈퇴 / 제명 (대표가 나가면 다음 사람이 대표) |
| `/office list` | 서버의 모든 사무소 |
| `/oc <메시지>` | 사무소 채팅 |

### 안(돈)과 협회 상점
- 돈과 평판은 **월드에 저장**된다 (은행 잔고). 죽어도 사라지지 않는다. 시작 잔고 500안.
- `/ahn pay <플레이어> <금액>`으로 송금.
- 협회 상점(게시판 화면의 `협회 상점` 버튼): 소모품, 책장, 무기, 장신구를 등급 제한에 맞춰 판다. 아이콘에 마우스를 올리면 툴팁이 보인다.
- **조직 책장, 조직 무기(쇠파이프 제외), 조직 장신구(동전·배지 제외)는 제작할 수 없다.** 상점이나 현상범에게서 얻는다.

## 책장 (Key Page)

책장 아이템을 우클릭하면 몸에 낀다. 낀 책장은 **능력치, 내성, 패시브, 겉모습(옷)**을 바꾼다.
책장은 인벤토리가 아니라 몸에 저장되며 **죽으면 잃는다**. `/keypage`로 정보 확인, `/keypage remove`로 벗기.

### 전투 규칙
- 물리 공격은 **참격 / 관통 / 타격**으로 나뉜다. 장검·도끼 = 참격, 단검·리볼버·화살·삼지창 = 관통, 철퇴·맨손·폭발 = 타격.
- 내성 배율: 치명 ×2 · 취약 ×1.5 · 보통 ×1 · 견딤 ×0.5 · 내성 ×0.25. 체력 내성과 흐트러짐 내성이 따로 있다.
- **흐트러짐**: 맞을 때마다 흐트러짐 게이지가 깎인다 (타격은 1.25배). 0이 되면 3초간 거의 움직이지 못하고 **받는 피해 2배**. 5초간 안 맞으면 초당 10%씩 회복.
- **HUD**: 핫바 왼쪽에 내 흐트러짐 게이지, 조준점 아래에 방금 때린 대상의 게이지가 4초간 표시된다. 흐트러지면 빨갛게 바뀐다.
- 몹도 게이지와 기본 내성이 있다 (스켈레톤: 관통 견딤·타격 취약, 좀비: 참격 취약·타격 견딤, 철 골렘: 관통 내성 등).
- 공격하면 액션바에 피해 유형과 상대의 내성이 뜬다.

책장이 없으면 흐트러짐 저항 20, 모든 내성 보통. 시작 키트에는 사무소 해결사의 책장이 들어 있다.
획득: 쥐·사무소 해결사 책장은 빈 책장(책 + 종이 + 먹물 주머니 + 금 조각)으로 제작. 조직 책장은 협회 상점 또는 현상범 드롭.
수치와 옷 디자인은 이 모드의 오리지널이며, 원작 수치나 의상을 그대로 옮긴 것이 아니다.

## 개발

```
./gradlew build        # build/libs/에 jar 생성
./gradlew runClient    # 개발용 클라이언트 실행
```

`fixer-city` 브랜치에 푸시하면 GitHub Actions가 빌드해서 Release로 올립니다. 빌드가 실패하면 로그 요약이 이슈로 올라옵니다.

```
src/main/java/com/fixercity/
  FixerCity.java          메인 클래스
  registry/               아이템, 방어구 재질, 데이터 컴포넌트, 크리에이티브 탭
  item/                   무기와 방어구 (기술 로직)
  keypage/                책장 정의(KeyPages), 내성, 패시브, 장착/동기화
  combat/                 피해 유형 판정, 내성, 흐트러짐, 패시브, 백스탭
  client/                 책장 옷 렌더 레이어, 흐트러짐 HUD, 게시판·상점 화면
  network/                책장·흐트러짐·게시판·상점 패킷
  request/                의뢰·평판·돈 (RequestManager), 의뢰 생성, 채팅 UI, 상점, 명령어, 월드 저장 데이터
  block/                  의뢰 게시판 블록
  event/FixerEvents.java  세트 효과, 지속 패시브, 접속/리스폰 처리, 명령어
  kit/FixerKit.java       시작 키트 구성
```

프로젝트문 세계관을 바탕으로 한 비공식 팬 모드입니다.
